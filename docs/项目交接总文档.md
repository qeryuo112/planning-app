> 本文档是 Plan（planning-app）项目的综合交接/开发总览，合并自各阶段文档与决策记录。它用于快速了解项目现状、环境、技术债务与后续方向，便于新人接手或后续开发。

## 1. 项目定位与目标

**Plan** 是一款以「目标 → 计划 → 执行 → 反馈 → 调整」为核心闭环的 **AI 个人成长管理工具**。当前版本明确为**个人使用版**，围绕目标、任务、习惯、提醒、复盘、日历、报表、AI 洞察等模块提供完整的执行与反馈体验。

MVP 成功标准（已达成）：

- 3 分钟内创建目标并得到首周可执行计划。
- 每日首页快速呈现「今天最重要的 3 件事」。
- 完成任务后即时看到目标进度、连续打卡和阶段反馈。
- 用户可随时调整计划，AI 不覆盖用户已有数据。
- Android 真机可安装运行，核心流程无崩溃、无白屏。

## 9. FCM 推送结论

- **服务端**：已通过 `/opt/mihomo` 代理成功把 FCM 消息投递到 Google。服务端日志可看到 `FCM 推送成功: messageId=...`。
- **手机端（国内直连）**：无法获取 Firebase Installations auth token（日志 `Failed to get FIS auth token`），因此即使服务端成功，真机也收不到通知。
- **手机端挂 VPN**：FCM 远程推送可正常送达。
- **个人版兜底**：无 VPN 时以 **本地通知 + WebSocket 实时提醒** 为主；FCM 远程推送作为补充。
- **商业版/国内大规模使用建议**：接入极光、小米、华为等国内推送通道。

## 11. 关键决策（来自 `decisions/` 目录）

- **个人使用版定位**：当前阶段聚焦个人多端使用，社交/商业功能代码保留但低优先级，不接入个人版离线同步。
- **不强制 VPN**：FCM 远程推送依赖 Google 服务，国内无 VPN 时以本地通知 + WebSocket 兜底，不阻塞核心体验。
- **离线优先**：Flutter 端本地 SQLite 缓存 + 操作队列，写操作本地优先、后台同步，弱网/断网不丢失数据。
- **本地通知兜底**：提醒扫描 15 秒一次 + WebSocket 实时广播，无 VPN 时本地通知仍可触达。
- **商业版功能低优先级**：订阅/会员、团队版、数据导出、社交深度、排行榜实时推送等暂不执行，保留在路线图。
- **服务器代理方案**：在服务器 `/opt/mihomo` 部署代理，仅让 Google/FCM 域名走代理，解决 `firebase-admin` 无法直连 Google 问题。
- **AI 模板策略**：6 个预置模板以 TypeScript 常量管理，关键词匹配；模板大量增加后再迁移数据库。
- **多模型路由**：单 `ModelAdapter` 实例内通过 `modelName` 参数切换 cheap/strong 模型；跨供应商时再拆分。
- **费用上限降级**：AI 日费用上限触发后优先降级为模板草案，未命中模板则使用通用占位。
- **社交共享**：采用「邀请-接受」模式，仅实现查看权限，挑战按全局行为计分，本次不做实时推送。
- **外部集成**：MVP 先用通用 ICS 导入/导出 + JSON 运动导入；Google/Outlook OAuth 与 Health Connect 作为后续深化。
- **报表来源**：直接基于现有 `Task`、`Checkin`、`Goal`、`User` 实时聚合，不新增专用聚合表。
- **AI 洞察**：画像摘要优先调用 strong 模型，失败/超限时回退规则摘要；个性化推荐先用规则驱动。
- **SSE 流式方案**：采用「阶段进度事件」而非逐 token 解析，接口拆分为 `POST /ai/plan-drafts/stream` + `GET /ai/plan-drafts/:id/stream`。
- **用户画像快照**：引入 `UserProfileSnapshot` 表，默认读快照，每周日 03:00 自动刷新，前端可手动刷新。

| 启动白屏 | 配置 Firebase 后 `main.dart` 在 `runApp` 前阻塞等待 FCM token | `FcmService.initialize()` 中 `_uploadToken()` 改为 `Future.microtask` 后台执行 |
| Firebase 组件被 R8 移除 | `ComponentDiscovery: Could not instantiate ...KtxRegistrar` | 新增 `proguard-rules.pro` 保留 `com.google.firebase.**` |
| HealthPlugin 注册失败 | `ClassCastException` 于 `GeneratedPluginRegistrant` | `MainActivity` 改为 `FlutterFragmentActivity` |
| 登录卡住/退出后需重新登录 | 无 VPN 时同步/FCM 无超时，启动页固定为登录页 | 增加 API 15 秒超时、同步后台化、新增 `SplashScreen` 自动校验 token |
| 资源 ID 无效 | 偶发 `Invalid resource ID 0x00000001` | Week 28 后未复现，继续观察 |
| OnBack 兼容警告 | `OnBackInvokedCallback is not enabled` | `AndroidManifest.xml` 添加 `android:enableOnBackInvokedCallback="true"` |
| FCM 真机收不到 | 国内直连无法获取 FIS auth token | 手机挂 VPN 后链路通；无 VPN 时本地通知兜底 |

## 13. 踩坑记录（合并版）

1. **GitHub 在 shell 中无法访问**：用户本地 VPN 不覆盖命令行，Flutter 最终改用腾讯镜像预编译 zip。
2. **服务器 `nest build` 压死 SSH**：单核 ECS 编译时 CPU 满载，改为本地构建后上传 `dist/`。
3. **`tar` 解压路径嵌套**：`tar -xzf planning-app-weekX.tar.gz` 默认创建 `/opt/planning-app/planning-app/` 嵌套目录，需用 `--strip-components=1`。
4. **`nest build` 缓存导致生成不完整**：已有 `dist/` 和 `tsconfig.tsbuildinfo` 时只生成 `.d.ts`，需删除后重新构建。
5. **`npx prisma migrate deploy` 需 source `.env`**：否则读取不到 `DATABASE_URL`，命令为 `set -a && source /opt/planning-app/.env && set +a`。
6. **SSE 被 Nginx 缓冲**：必须配置 `proxy_buffering off; proxy_cache off; proxy_read_timeout 300s;`。
7. **Google OAuth 首次授权需 `prompt: 'consent'`**：否则拿不到 `refresh_token`。
8. **Health Connect 需手动安装**：国内部分 Android 设备未预装 Google Health Connect 应用。
9. **Android `health` 插件要求 `minSdk 26` / `compileSdk 36`**：需 patch Pub Cache 或统一 `subprojects` 脚本。
10. **Windows 桌面无 FCM/本地通知**：`firebase_messaging` 与 `flutter_local_notifications` 不支持 Windows，桌面平台直接返回。
11. **Firebase ProGuard 规则**：R8 压缩后 `*KtxRegistrar` 被移除，需 `-keep class com.google.firebase.** { *; }`。
12. **FCM 代理需 `HttpsProxyAgent`**：仅设置 `HTTPS_PROXY` 环境变量对 `firebase-admin` 内置 HTTP 客户端无效，必须显式创建 `HttpsProxyAgent` 传入 `cert(..., proxyAgent)` 与 `initializeApp({ httpAgent: proxyAgent })`。
13. **手机端需 VPN 才能收到 FCM**：国内直连无法获取 Firebase Installations auth token。
14. **systemd `EnvironmentFile` 对 JSON 字符串转义不友好**：`GOOGLE_APPLICATION_CREDENTIALS_JSON` 推荐配置为 JSON 文件绝对路径，由 `FcmService` 读取文件。
15. **`flutter_local_notifications` 需显式创建 Android 通知渠道**：否则通知可能被系统静默。
16. **SQLite 构建钩子下载 GitHub 预编译库超时**：加入 `sqlite3_flutter_libs` 与 `hooks.user_defines.sqlite3.source: system`。
