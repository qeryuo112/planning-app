## 1. 项目定位与目标

一款以“目标—计划—执行—反馈—调整”为核心闭环的 **AI 个人成长管理工具**。MVP 成功标准：

- 3 分钟内创建目标并得到首周可执行计划。
- 每日首页快速呈现“今天最重要的 3 件事”。
- 完成任务后即时看到目标进度、连续打卡和阶段反馈。
- 用户可随时调整计划，AI 不覆盖用户已有数据。
