## 1. 项目定位

一款以“目标—计划—执行—反馈—调整”为核心闭环的 **Plan - AI 个人成长管理工具**。当前明确为**个人使用版本**，核心目标是让个人用户在 3 分钟内创建目标并得到首周可执行计划，每日首页快速呈现“今天最重要的 3 件事”。

### 1.1 MVP 成功标准

- 3 分钟内创建目标并得到首周可执行计划。
- 每日首页快速呈现“今天最重要的 3 件事”。
- 完成任务后即时看到目标进度、连续打卡和阶段反馈。
- 用户可随时调整计划，AI 不覆盖用户已有数据。

## 6. 关键踩坑记录

1. **服务器 `nest build` 压死 SSH**：单核 ECS 编译 TypeScript 时 CPU 满载，SSH banner 交换超时。当前改为**本地构建后上传 `dist/`**。
2. **tar 解压路径嵌套**：`tar -xzf planning-app-weekX.tar.gz` 默认创建 `/opt/planning-app/planning-app/` 嵌套目录。需用 `--strip-components=1`。
3. **`nest build` 缓存导致生成不完整**：已有 `dist/` 和 `tsconfig.tsbuildinfo` 时只生成部分 `.d.ts`。需删除后重新构建。
4. **`npx prisma migrate deploy` 不会自动加载 `.env`**：需先 `set -a && source /opt/planning-app/.env && set +a`。
5. **SSE 通过 Nginx 被缓冲**：必须配置 `proxy_buffering off; proxy_cache off; proxy_read_timeout 300s;`。
6. **Google OAuth 首次授权需 `prompt: 'consent'`**：否则无法拿到 `refresh_token`。
7. **Health Connect 在国内部分 Android 设备需手动安装**：Google Health Connect 应用。
8. **Flutter `health` 包 `uuid` 非空**：无需 null-aware 表达式。
